# Cross-Stitch Pattern Generator

Приложение для автоматического создания схем для вышивки крестом из изображений.

Я разработала этот инструмент, чтобы превращать фотографии и изображения в готовые схемы для вышивки с расчётом цветов, количества крестиков и необходимых ниток.

## Что умеет приложение

- преобразовывать изображение в схему для вышивки крестом
- подбирать и оптимизировать цветовую палитру
- работать с палитрами ниток DMC и Gamma
- создавать символьную схему для вышивания
- рассчитывать размер готовой вышивки в зависимости от канвы
- считать количество стежков для каждого цвета
- рассчитывать примерный расход ниток и количество мотков
- формировать готовую схему в PDF
- показывать предварительный результат перед сохранением

## Как это работает

Пользователь загружает изображение, выбирает размер схемы, количество цветов и параметры канвы. Приложение анализирует изображение, переводит его в систему крестиков и цветов и создаёт готовую схему с легендой и расчётом материалов.

## Technology

Python · Tkinter · Pillow · ReportLab · NumPy
